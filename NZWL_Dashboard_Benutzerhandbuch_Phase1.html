1. Überblick – Was ist das NZWL Dashboard?

Das NZWL Dashboard ist eine webbasierte Anwendung für den ZWL-Kreis zur Überwachung und Steuerung von Kreditoren-Verbindlichkeiten. Das System verknüpft automatisch offene Rechnungen (Kreditoren) mit den zugehörigen Endkunden (Debitoren) und zeigt auf einen Blick, welche Zahlungen wann fällig sind.

Kernfunktionen Phase 1

FunktionBeschreibung
DashboardKennzahlen, Top-Kreditoren-Diagramme, Match-Quote, Statistik
FälligkeitenAlle Belege mit Ampel-Status, Filter, Sortierung, Sammel-Aktionen, Pagination
Kreditor-DebitorDetailansicht der Verknüpfung: Rohteil → Fertigteil → Endkunde
Nicht verknüpftAnalyse der nicht zuordenbaren Belege nach Grund und Branche
Ampel-SystemBelege per Klick als Rot/Gelb/Grün markieren – revisionssicher
Admin-BereichNutzerverwaltung, Ampel-Historie, System-Rollback
CSV-ExportAlle Seiten mit Download-Option
GesellschaftsfilterDaten nach NZWL oder ZWL SK einschränken
Datenquelle Die Daten stammen aus der Kernlogik – einem automatisierten Prozess, der SAP-Daten analysiert und Kreditoren mit Debitoren über eine 4-Schritt-Kette (Rohteil → BOM → Fertigteil → Debitor) verknüpft.
Demo-System Phase 1 läuft im Testbetrieb. Auf dem Login-Bildschirm erscheint ein entsprechender Hinweis. Die Zugangsdaten sind vorläufig.

2. Zugang & Anmeldung

Dashboard aufrufen

Öffnen Sie einen Webbrowser (Chrome oder Edge empfohlen) und rufen Sie die folgende Adresse auf:

Dashboard-URL http://<Server-IP>:8501
Die genaue Server-Adresse erhalten Sie von Ihrem Projektleiter oder der IT-Abteilung.

Anmeldevorgang

  1. Benutzername eingeben
    Tragen Sie Ihren persönlichen Benutzernamen ein.
  2. Passwort eingeben
    Tragen Sie Ihr Passwort ein.
  3. „Einloggen“ klicken
    Bei Erfolg gelangen Sie direkt zur Startseite (Dashboard).

7. Das Ampel-System (Traffic Lights)

Das Ampel-System ist das zentrale Steuerungselement für die Zahlungsfreigabe in Phase 1. Jeder Beleg kann mit einem von vier Status versehen werden.

Die vier Status

AmpelStatusBedeutungTypische Verwendung
🔴Rot Stop / Prüfen Zahlung stoppen – Beleg muss geprüft werden
🟡Gelb In Prüfung Beleg wird gerade geprüft, Entscheidung steht noch aus
🟢Grün Freigegeben Zahlung kann ausgeführt werden
⚪Kein Status Nicht bearbeitet Beleg wurde noch nicht bewertet

So setzen Sie einen Ampel-Status

  1. Öffnen Sie die Fälligkeiten-Seite
    Navigieren Sie über die Seitenleiste zu „Fälligkeiten“.
  2. Finden Sie den Beleg
    Nutzen Sie die Filter (Kreditor, Woche, Zeitraum) oder blättern Sie durch die Tabelle.
  3. Klicken Sie auf die gewünschte Ampel-Farbe
    In der Spalte „Ampel“ sehen Sie drei Kreise (🔴 🟡 🟢). Der aktive Status leuchtet farbig, die anderen sind ausgegraut. Klicken Sie auf die gewünschte Farbe.
  4. Status zurücksetzen
    Klicken Sie erneut auf die bereits aktive Farbe – der Status wird zurückgesetzt.
Revisionssicherheit Jede Ampel-Änderung wird automatisch und unwiderruflich protokolliert – mit Belegnummer, neuem Status, Zeitstempel und Benutzername. Diese Historie kann nicht gelöscht werden (Append-Only-Prinzip).

Sammel-Aktionen für mehrere Belege

Um den Status für viele Belege gleichzeitig zu setzen:

  1. Filtern Sie die Tabelle auf die gewünschten Belege (z.B. alle Belege eines Kreditors)
  2. Öffnen Sie den Bereich „Sammel-Aktionen“
  3. Klicken Sie auf den gewünschten Status-Button (z.B. 🟢 „Alle Freigeben“)

Alle aktuell sichtbaren (gefilterten) Belege erhalten den neuen Status.

10. Seite: Admin-Bereich

Nur für Administratoren Diese Seite ist ausschließlich für Benutzer mit der Rolle Admin sichtbar.

Tab 1: Nutzerverwaltung

  • Tabelle aller Benutzer (Name, E-Mail, Rolle, Gesellschaft)
  • Formular zum Anlegen neuer Benutzer (Demo-Modus: nur für die aktuelle Sitzung)

Tab 2: Beleg-Statusverlauf (Ampel-Historie)

Zeigt alle jemals durchgeführten Ampel-Änderungen in chronologischer Reihenfolge.

Filter:

  • Belegnummer – Freitextsuche
  • Geändert von – nach Benutzer filtern
  • Ampel-Status – nach Status filtern (Rot, Gelb, Grün, Zurückgesetzt)

Die Historie kann als CSV-Datei exportiert werden („Historie als CSV exportieren“).

System-Wiederherstellung (Ampel-Rollback)

Mit dieser Funktion können alle Ampel-Status auf einen historischen Zeitpunkt zurückgesetzt werden.

  1. Datum und Uhrzeit wählen
    Wählen Sie den Zeitpunkt, zu dem Sie den Zustand wiederherstellen möchten.
  2. Vorschau prüfen
    Das System zeigt, welche Belege sich ändern würden (Aktueller Status → Ziel-Status).
  3. Bestätigen und ausführen
    Setzen Sie das Häkchen bei „Ja, ich möchte zurücksetzen“ und klicken Sie auf „Rollback ausführen“.
Achtung Der Rollback wird im Audit-Log dokumentiert. Jede Änderung wird als „[Admin-Name] (Rollback auf TT.MM.JJJJ HH:MM)“ protokolliert. Der Rollback selbst ist also revisionssicher nachvollziehbar.

12. Hinweise & FAQ

Wie aktualisiere ich die Daten?

Klicken Sie in der Seitenleiste auf „Cache leeren“. Auf dem Dashboard gibt es zusätzlich den Button „Daten neu laden“. Auf dem Windows-Server kann die Kernlogik über „Kernlogik ausführen“ direkt aus dem Dashboard gestartet werden.

Warum ist eine Ampel-Farbe ausgegraut?

Ausgegraute Farben bedeuten, dass dieser Status nicht aktiv ist. Die leuchtende Farbe zeigt den aktuellen Status. Alle drei Farben ausgegraut bedeutet: kein Status gesetzt.

Kann ich eine Ampel-Änderung rückgängig machen?

Einzelner Beleg: Klicken Sie erneut auf die aktive Farbe – der Status wird zurückgesetzt.
Mehrere Belege: Nutzen Sie die Rollback-Funktion im Admin-Bereich, um alle Belege auf einen früheren Zeitpunkt zurückzusetzen.

Was bedeutet „Nicht verknüpft“?

Ein Beleg ist „nicht verknüpft“, wenn die Kernlogik keinen Endkunden (Debitor) dafür ermitteln konnte. Die Gründe werden auf der gleichnamigen Seite aufgeschlüsselt.

Welchen Browser soll ich verwenden?

Google Chrome oder Microsoft Edge (empfohlen). Firefox wird ebenfalls unterstützt. Internet Explorer wird nicht unterstützt.

Warum steht „Demo-System“ auf dem Login?

Das System befindet sich noch im Testbetrieb (Phase 1). Der Hinweis wird entfernt, sobald der Produktivbetrieb beginnt.

An wen wende ich mich bei Fragen?

Bitte kontaktieren Sie Ihren Projektleiter oder die IT-Abteilung.
